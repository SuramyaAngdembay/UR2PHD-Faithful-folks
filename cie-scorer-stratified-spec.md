# CIE-Scorer on the blind stratum — spec frozen before any GPU time was spent (2026-09-21)

## Question

Does a published, trained, internals-based detector break the blind regime that ten prompted judges
could not? CIE-Scorer (Shen et al., arXiv:2605.25603; from the FaithCoT-Bench group) reports
Acc/F1 of 69.0/60.8 (LogiQA), 78.0/71.5 (TruthfulQA), 77.0/72.8 (AQuA) and 78.0/79.7 (HLE-Bio) on
Llama-3.1-8B-Instruct traces. Nobody has reported it by answer correctness. Two outcomes are both
useful: if it separates honest from unfaithful errors, headroom exists and we learn it lives in the
generator's internals; if it does not, the ceiling extends from prompted judges to a trained detector.

## What is and is not available (verified 2026-09-21)

The release (`se7esx/CIE-Scorer` @ `06911c9`) states it ships **no checkpoints**. It does ship the
circuit builder, the graph-dataset builder and the detector training script, so the detector must be
**retrained by us**. This is therefore a *reproduction from released code*, not an evaluation of the
authors' model. Known gaps between release and paper, none resolvable from public materials:

- The paper's Table 3 lists a batch size (8-10); the released `train()` updates per trace.
- The paper uses GNN width 256 (128 for HLE-Bio); the code defaults to 128. We follow the paper.
- The split ratios and epoch count are not stated in the paper; we use the code defaults
  (test 0.4, validation 0.3 of the remainder, 20 epochs, seed 42).
- **The released script's final line labelled "Test" evaluates on train + validation + test
  records together.** Its per-epoch log carries a genuinely held-out test metric. We report both,
  because which one matches Table 1 is informative about how the published numbers were produced.
  We do not assert that the paper used that line.

## Population

FaithCoT-Bench traces generated by **Llama-3.1-8B-Instruct only** — the method needs the generator's
weights and its matched transcoders (`facebook/crv-8b-instruct-transcoders`, public, 68.7 GB).
307 labelled traces: **blind regime (ft1 v ft2) n = 144, 84 unfaithful; correct regime (ft3 v ft4)
n = 163, 26 unfaithful.** Regimes keyed on `ft`, never on the inverted `correct` field.

**Power, stated now.** At n = 144 a bootstrap interval on AUROC is about ±0.09; the correct regime
has 26 positives. This experiment can detect a large effect and cannot resolve a small one.

## Stages and budget — hard cap 100 SU on `tra250034-ai` (H100 80 GB, 1 SU = 1 GPU-hour)

| stage | what | SU ceiling |
|---|---|---|
| 0 | environment, weights, transcoders, data — login node | 0 |
| 1 | timing smoke: circuits for 4 traces (one per domain), graph conversion, one training epoch. Functionality and timing only. | 1.5 |
| 2 | circuits for all 307 traces, with the paper's per-dataset token-selection λ, β | 60 |
| 3 | reproduction check (per-dataset training) | 10 |
| 4 | out-of-fold scores for the stratified analysis | 20 |

**Gate after stage 1:** if the projected cost of stage 2 exceeds 60 SU, stop and report rather than
cut scope silently. Usage is read from `sacct`, not estimated. The smoke's four traces are used for
timing and plumbing only; no accuracy quantity is computed from them.

## Stage 3 — does the reproduction reproduce?

Per dataset, paper hyperparameters (Table 3: λ, β, α, GNN layers, width, learning rate), released
split logic, seeds 0-4. Reported: held-out test Acc/F1 at the validation-selected epoch and
threshold, and the all-records figure the released script prints. **Reproduction counts as
successful if held-out F1 is within 10 points of Table 1 on at least three of four datasets** (test
sets are 16-40 traces, so tighter agreement is not expected). If it fails, stage 4 still runs but
its result is labelled "a detector trained with the released code", not "CIE-Scorer".

## Stage 4 — the stratified question (primary)

Every one of the 307 traces receives an **out-of-fold** continuous `unfaithful_score`: 5-fold
cross-validation stratified on the four `ft` cells, threshold-free, scores averaged over seeds 0-4.
Primary model: one detector pooled across the four datasets (most data, comparable scores), with
λ = β = 0.5 for all datasets so that circuits are built identically; the per-dataset variant is
secondary. Endpoints, question-clustered bootstrap, 2000 draws, seed 0:

- AUROC in the blind regime and in the correct regime.
- **Paired difference against the gpt-4o-mini judge (prompt A) on the same traces**, and against
  the best local judge. Our existing linear probe (Llama, blind, held-out 0.67) is quoted for
  context but was not run on these folds.
- AUROC of the CIE score against **answer incorrectness**, and pooled-versus-within-regime AUROC —
  the test of whether a trained detector's pooled gain is composition, as our paper argues for
  metrics and judges.

**Decision rule, fixed now.**
- **BREAKS THE BLIND REGIME** — blind AUROC >= 0.75 *and* exceeds the judge on the same traces by
  >= 0.05 with the paired 95% interval excluding zero.
- **CEILING EXTENDS** — blind AUROC < 0.70 *and* the paired difference against the judge covers
  zero or is negative.
- **MIXED** — anything else, reported as is.

My expectation, recorded so it cannot move: about 35% on BREAKS. Our own linear probe on the same
model reached 0.67 held-out, which is evidence internals carry some signal; the detector was trained
for pooled accuracy, which is evidence it may have learned correctness.

## What this cannot show

It covers one generator and 307 traces. A positive result would show the signal is in Llama's
internals, not that a deployable monitor exists for closed models. A negative result binds this
detector as retrained by us, with the release-versus-paper gaps listed above.
